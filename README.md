# MES Decision Lab

MCA03·MCA36 정비 시나리오를 비교하는 정적 웹 시뮬레이터. 별도 설치·빌드·DB 인증 없이 실행합니다.

- 배포 자산: `dist/` (HTML, CSS, JavaScript)
- 모델 검증: `node tests/model.test.js`
- 로컬 실행: `python -m http.server 8765 --directory dist`
- 배포: GitHub Settings → Pages → Source를 **GitHub Actions**로 선택. `main` push 또는 Actions의 수동 실행으로 배포합니다.

기존 불량률, 정비 효과, 추가 능력, 날짜·휴무 가정을 바꿀 수 있습니다. 비교표 클릭, CSV 다운로드, URL 해시로 설정 공유를 지원합니다. 브라우저 내에서만 계산하며 외부 라이브러리·추적 도구·DB 연결은 없습니다.

## 모델 경계

실제 고객 납기 예측이 아닌 조건부 물량 모델입니다. SQLcl로 조회한 정비 전 2026-08-27~09-02 불량 기록: MCA03 2,409개, MCA36 1,951개, 각 불량 등록일 6일. 등록일이 실제 가동일이라는 보장은 없습니다.

일생산능력은 평균 불량 / 가정 불량률로 역산합니다. 목표는 정비 없이 생산할 정상 양품 물량이며 실제 고객 주문량이 아닙니다. 기존 재고·미납 0, 두 설비에 같은 기존 불량률 적용, 설비 간 대체 없음, 정비 다음날 즉시 복귀를 가정합니다. 불량은 기한 내 회복되지 않는 양품 손실로 취급합니다. 금형·자재·인력·셋업·후속 공정·운송 제약은 미포함입니다.

기본 날짜: 2026-09-03 정비 / 09-10 납기. 일요일 휴무, 납기 당일 생산 포함. 정비 없으면 7일, 정비 후 6일입니다.

목적은 미충족 양품 최소화 → 추가 생산 최소화 → 기대 불량 최소화입니다. 제약이 설비별로 분리되므로 선형계획의 해를 수식으로 계산합니다. 기존 scipy 선형계획 결과 27개 시나리오와 수치 일치를 검증합니다.

정비 후 불량률 `d1=d*(1-r)`, 목표 `D=B*(1-d)`(정상 일생산능력 단위), 필요 총생산 `D/(1-d1)`, 가능 총생산 `T*(1+u)`, 최적 생산 `min(D/(1-d1), T*(1+u))`. 전량 확보 최소 추가 능력 `max(0,D/(T*(1-d1))-1)`.

사이트에 표시되는 집계값과 모델 입력은 배포 자산에 포함됩니다. 원본 스킬, DB 접속정보, Wallet, 주문·사원 상세 데이터는 포함하지 않습니다.
